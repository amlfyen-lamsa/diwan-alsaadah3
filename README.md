# ديوان السعادة – نغم يجمعنا (Dewan Al Saada)
## المنصة الرقمية والتطبيق الموسيقي الرسمي للقناة

موقع وتطبيق ويب تقدمي (PWA) متكامل مصمم خصيصاً لإحياء وتوثيق الأغنية اليمنية والخليجية والتراث الصنعاني والحضرمي واللحجي والعدني، مع نظام راديو رسمي مستمر، ومكتبة فيديو، واستخراج صوت MP3 بجودة استوديو، ومزامنة دورية لقناة ديوان السعادة.

---

## 🌟 المزايا والوظائف الرئيسية

1. **مكتبة الفيديوهات والجلسات الحية**:
   - تشغيل متجاوب متطور عبر YouTube IFrame Player API بنسبة أبعاد 16:9 مع كشف الأخطاء التلقائي.
   - تنزيل مباشر لملفات الفيديو الأصلية (MP4 - H.264 / AAC) مع دعم HTTP Range واستئناف التحميل السريع.
   - استخراج وتنزيل الملفات الصوتية الأصلية (MP3) بجودة تصل إلى 320 kbps.

2. **ديوان السعادة – الراديو الرسمي**:
   - **الوضع الأول: راديو أغاني ومكتبة الموقع**: تشغيل تسلسلي مستمر للأغاني بالترتيب، الانتقال التلقائي، تقديم وترجيع، تشغيل عشوائي وتكرار، والتحكم بالصوت.
   - **الوضع الثاني: بث القناة الحي المباشر**: ربط فوري برابط البث الصوتي المعتمد مع كشف حالة الاتصال وإعادة الاتصال الذاتية.
   - **مشغل ثابت وسلس**: استمرار الصوت أثناء تصفح جميع أقسام المنصة، مع دعم كامل لـ Media Session API لعرض اسم الأغنية وأزرار التحكم في شاشة القفل.

3. **تطبيق مستقل مجاني (PWA)**:
   - قابل للتثبيت كـ Progressive Web App على هواتف Android و iPhone وأجهزة Windows و Mac.
   - يعمل كأيقونة مستقلة باسم "ديوان السعادة" مع دعم العمل دون اتصال للواجهات وتحديث تلقائي للخدمة.

4. **التصنيفات الـ 19 المعتمدة**:
   - الأغاني الحضرمية، الأغاني الخليجية، الأغاني الصنعانية، الشرح اللحجي، الأغاني العدنية، أغاني أيوب طارش، الأغاني المصرية، القدود الحلبية، الفنان أسامة المقدم، جلسات أحلى شباب، جلسات محمد قائد، أغاني محمد الجنيد، أغاني محمد أبكر، أغاني أبوبكر سالم، أغاني فيصل علوي، أغاني محمد مرشد ناجي، أغاني محمد سعد عبدالله، جلسات العود والتقاسيم، والشيلات.

5. **تواصل ورعاية المواهب**:
   - نموذج مخصص للمطربين والعازفين والشعراء للتواصل المباشر مع المشرف العام الأستاذ **محمد قائد** (+967 733 600 800) عبر رسائل واتساب مهيكلة.

6. **لوحة تحكم إدارة محمية**:
   - محمية برمز مرور مشفر على الخادم.
   - مزامنة آلية كل 15 دقيقة مع قائمة القناة الرسمية لمنع التكرار نهائياً.
   - إدارة كاملة للفيديوهات، كلمات الأغاني، الفنانين، التصنيفات، والراديو، وتصدير نسخة الإنتاج الكاملة.

## ⚡ النشر السريع على GitHub و Vercel

### 1. الرفع إلى مستودع GitHub
المشروع مجهز بالكامل بملف `.gitignore` قياسي يستبعد الملفات المؤقتة والسرية:
```bash
git init
git add .
git commit -m "feat: تجهيز نسخة الإنتاج لديوان السعادة"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/dewan-al-saada.git
git push -u origin main
```

### 2. النشر الفوري بنقرة واحدة على Vercel
المشروع مزود بملف إعدادات `vercel.json` ومعمارية `api/index.ts` لدعم التوزيع السحابي السريع:
1. افتح منصة **[Vercel](https://vercel.com/new)** وسجل الدخول بحساب GitHub الخاص بك.
2. اختر مستودع **dewan-al-saada** واضغط **Import**.
3. في إعدادات المشروع (Project Settings):
   - **Framework Preset**: سيتم التعرف عليه تلقائياً كـ **Vite**.
   - **Build Command**: `npm run build` (مضبوط تلقائياً).
   - **Output Directory**: `dist` (مضبوط تلقائياً).
4. أضف متغيرات البيئة (Environment Variables) في Vercel:
   - `LIBRARY_ACCESS_CODE`: `1#7a4`
   - `YOUTUBE_CHANNEL_ID`: `UC2XgHgOGcGcDJHjb7DkB2Mg`
   - `GEMINI_API_KEY`: مفتاح Gemini الخاص بك (اختياري لتفعيل الذكاء الاصطناعي).
5. اضغط **Deploy**؛ سيتم بناء ونشر الموقع خلال أقل من دقيقة مع نطاق HTTPS مجاني وسريع حول العالم!

## 🛠️ خطوات التثبيت والتشغيل على خادم جديد

### 1. استخراج الحزمة وتثبيت الاعتماديات
```bash
# الانتقال لمجلد المشروع
cd dewan-al-saada

# تثبيت الحزم المطلوبة
npm install
```

### 2. إعداد متغيرات البيئة
انسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
وقم بضبط المتغيرات بحسب بيئتك:
- `PORT`: منفذ الخادم (افتراضياً 3000).
- `LIBRARY_ACCESS_CODE`: رمز الدخول السري للوحة الإدارة (افتراضياً `1#7a4`).
- `YOUTUBE_CHANNEL_ID`: معرف القناة (`UC2XgHgOGcGcDJHjb7DkB2Mg`).
- `YOUTUBE_API_KEY`: مفتاح YouTube Data API v3 (اختياري، المنصة تتزامن تلقائياً أيضاً عبر الـ Feed الرسمي دون مفتاح).

### 3. بناء نسخة الإنتاج
```bash
npm run build
```

### 4. تشغيل الخادم
```bash
# تشغيل دائم عبر Node/TSX
npm start

# أو باستخدام PM2 لإدارة الخادم بشكل مستمر:
pm2 start server.ts --name "dewan-al-saada" --interpreter ./node_modules/.bin/tsx
```
